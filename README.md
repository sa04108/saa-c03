# [saa-c03.hyunbbai.com](https://saa-c03.hyunbbai.com)

AWS SAA-C03(Solutions Architect – Associate) 자격증을 준비하는 분들을 위한 학습 사이트입니다. 핵심 개념을 정리하고, 문제를 풀며 정답과 해설로 복습할 수 있습니다.

## 학습 자료

- [개념 위키](https://saa-c03.hyunbbai.com/concepts/): 핵심 개념 62개와 개념별 문제 풀이
- [문제집](https://saa-c03.hyunbbai.com/dumps/): 684문제와 정답·해설, 풀이 기록 자동저장

## 이용 방법

1. **개념 위키**에서 궁금한 서비스나 용어를 검색하고, 연결된 문제로 이해한 내용을 확인하세요.
2. **문제집**에서 답을 선택한 뒤 **정답 · 해설 확인**을 눌러 채점하세요. 여러 답을 고르는 문제는 안내된 개수만큼 선택하면 됩니다.
3. 다시 보고 싶은 문제에 **별표**를 표시하세요. **학습 범위**에서 **틀린 문제**나 **별표 문제**만 모아 복습할 수 있습니다.

페이지 우상단 버튼으로 개념 위키와 문제집을 오갈 수 있습니다. 문제집에서는 내용 검색이나 문제 번호 입력으로 원하는 문제를 찾을 수 있습니다.

## 이어풀기와 백업

로그인 없이 선택한 답, 채점 결과, 별표와 마지막 문제가 자동으로 저장됩니다. **같은 기기와 브라우저**로 다시 방문하면 이어서 풀 수 있습니다.

다른 기기나 브라우저로 기록을 옮기려면 문제집의 **저장 · 백업** 메뉴에서 **백업 JSON 저장**으로 파일을 내려받고, 새 기기에서 **백업 불러오기**로 가져오세요. **진행 포함 HTML 저장**을 선택하면 문제와 현재 진도를 한 파일로 보관할 수도 있습니다.

시크릿 모드 종료나 사이트 데이터 삭제로 기록이 사라질 수 있으니, 중요한 진도는 백업해 두세요.
