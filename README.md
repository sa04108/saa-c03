# [saa-c03.hyunbbai.com](https://saa-c03.hyunbbai.com)

AWS SAA-C03(Solutions Architect – Associate) 자격증을 준비하는 분들을 위한 학습 사이트입니다. 핵심 개념을 정리하고, 문제를 풀며 정답과 해설로 복습할 수 있습니다.

## 학습 자료

- [개념 위키](https://saa-c03.hyunbbai.com/concepts/): 핵심 개념 62개와 개념별 문제 풀이
- [문제집](https://saa-c03.hyunbbai.com/dumps/): 684문제와 정답·해설, 풀이 기록 자동저장

## 이용 방법

1. **개념 위키**에서 궁금한 서비스나 용어를 검색하고, 연결된 문제로 이해한 내용을 확인하세요.
2. **문제집**에서 답을 선택한 뒤 **정답 · 해설 확인**을 눌러 채점하세요. 여러 답을 고르는 문제는 안내된 개수만큼 선택하면 됩니다.
3. 다시 보고 싶은 문제에 **별표**를 표시하세요. **학습 범위**에서 **틀린 문제**나 **별표 문제**만 모아 복습할 수 있습니다.
4. 어려운 개념이나 문제는 카드의 **로봇 아이콘**으로 AI에 질문하세요. 예상 질문 4개 중 하나를 고르면 입력창에 채워지며, 내용을 수정한 뒤 **전송 버튼**을 눌러 답변을 받을 수 있습니다. 화면 우측 하단의 로봇 버튼으로 자유롭게 질문할 수도 있습니다.

AI 어시스턴트는 로그인 없이도 이용할 수 있습니다. PC에서는 **Enter로 전송**, **Shift+Enter로 줄바꿈**합니다. **새 대화(연필)**를 누르면 문제·개념에서 벗어나 자유 질문으로 시작합니다. 모바일에서는 전체 화면으로 열리며 우상단 닫기 버튼으로 학습 화면에 돌아올 수 있습니다. 답변에는 오류가 있을 수 있으므로 중요한 내용은 AWS 공식 문서와 함께 확인하세요.

GitHub 계정을 연동하면 대화가 계정에 저장됩니다. 하나의 기록에는 첫 질문부터 이어진 전체 대화가 담기며, 후속 질문도 같은 채팅방에 쌓입니다. 연필 왼쪽의 **대화 기록** 버튼에서 이전 대화를 선택해 다른 기기에서도 이어서 질문할 수 있습니다. **대화 기록에 저장됨** 표시를 확인하고 페이지를 닫으세요. 로그인하지 않은 대화는 현재 페이지에서만 볼 수 있으며, 새로고침하면 사라집니다.

실제 해설이 없는 문제에는 **ChatGPT explanation**을 영어 3문장 이내로 보충했습니다. 원문 답안·해설의 오류나 변경 사항은 **ChatGPT correction**에서 확인할 수 있습니다. 명확한 오류는 정정 답안으로 채점하며, 답을 확정하기 어려운 문제는 **답안 확인 필요**에 모아 자동채점에서 제외합니다.

페이지 우상단 버튼으로 개념 위키와 문제집을 오갈 수 있습니다. 문제집에서는 내용 검색이나 문제 번호 입력으로 원하는 문제를 찾을 수 있습니다.

## 이어풀기와 백업

시작 화면의 **소셜 계정**에서 **계정 연동**을 선택하면 선택한 답, 채점 결과, 별표와 마지막 문제를 GitHub 계정으로 저장합니다. 다른 기기에서도 같은 계정으로 로그인해 이어서 풀 수 있습니다. 문제집 우측 상단의 GitHub 아이콘으로도 계정을 연동할 수 있으며, 이미 로그인했다면 소셜 계정 영역으로 이동해 계정을 확인하거나 로그아웃할 수 있습니다.

로그인 없이도 **현재 기기와 브라우저**에 자동으로 저장하며 이용할 수 있습니다. 로그인 후 기존 기기 기록을 옮기려면 문제집의 **저장 · 백업 → 이 기기의 기존 기록 가져오기**를 선택하세요. 계정의 기존 진도가 있다면 먼저 백업해 두세요.

다른 기기나 브라우저로 기록을 옮기려면 문제집의 **저장 · 백업** 메뉴에서 **백업 JSON 저장**으로 파일을 내려받고, 새 기기에서 **백업 불러오기**로 가져오세요. **진행 포함 HTML 저장**을 선택하면 문제와 현재 진도를 한 파일로 보관할 수도 있습니다.

시크릿 모드 종료나 사이트 데이터 삭제로 기기 기록이 사라질 수 있으니, 중요한 진도는 백업해 두세요. 로그인한 경우에도 **계정 저장 완료** 표시를 확인한 뒤 페이지를 닫으면 됩니다.
